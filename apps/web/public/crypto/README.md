# Crypto logos

Colour SVGs from the [`cryptocurrency-icons`](https://github.com/spothq/cryptocurrency-icons) package, v0.18.1, CC0 1.0
(see LICENSE.md), vendored as files rather than installed as a dependency. File name = lower-case ticker.

Used by `AssetMark` only as a fallback: a logo uploaded to the asset registry always wins. A logo shows which asset a
ticker refers to; it is not an endorsement by, or affiliation with, the project.
